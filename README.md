# Телеграмм-бот для тренировочного процесса

Проект представляет из себя монорепозиторий PNPM с двумя пакетами
- Backend на Nest JS
- telegram-бот на Grammy JS

Проекты запускать отдельно, несмотря на то, что это монорепозиторий, то есть не использовать рекурсивный старт проекта через флаг -r, есть проблема с зависимостями.
Телеграмм-бот зависит от бекенда, поэтому сначала стартуем бекенд, а после успешного старта бекенда - стартуем бота
На сервере запускаем каждый проект через программу pm2
Docker не используется на проекте

Бот имеет два контура: dev- и prod-контур
Адрес prod-контура: @fit_way_bot
Адрес dev-контура: @fit_way_dev_bot
